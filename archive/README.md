# Archive — the toy-scale phases (2026-08-21 .. 2026-08-28)

This directory preserves, untouched, the pre-registered toy-scale program that
established the mechanism this project now builds on: PLAN.md (the governing
spec, v1.0-v1.27), plan/ (protocol, ledger, amendments, all review rounds,
retrospectives, tie-breaks, the Task D benchmark plan), and the coder briefs.

What it proved, with receipts in plan/ and results/:
- Necessity: the wire carries an instruction across a provably impassable
  attention gap — 100% vs an exact 12.5% cue-blind ceiling, all seeds (G0-G2
  green; Phase 3 archive runs under sha effd13e).
- Readable focus: a linear probe decodes the active task from the wire at
  87.5% (32-way, chance 3.1%).
- Steerable focus: transplanting the wire state made the same trunk execute a
  different stored rule 45/45 times.
- Honest negatives: a trivial latch matched or beat the oscillator on every
  latch-shaped task (comparators demanded by an adversarial review and kept
  binding by pre-registration); the k=32 cell exposed unreliable wire adoption.

The live project continues at the repository root: GPT2-PLAN.md.

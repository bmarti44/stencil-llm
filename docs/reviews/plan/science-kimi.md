Task M registers eight queried answers per sequence ("8 queried keys sampled without replacement", Section 6 Task M), so each sequence's mean accuracy takes values in {0, 1/8, ..., 1} — fractional, not a Bernoulli outcome. A binomial test with n = 10,000 requires an integer count of binary trials; the registered statistic cannot be computed as written. The escape readings are all unregistered or contradictory: treating all 80,000 answers as trials abandons the parenthetical's own sequence unit ("sequence-mean accuracy as the unit") and is anti-conservative under the positive within-sequence dependence a routing model induces; a binary per-sequence reduction has no registered null (e.g., any-correct-per-sequence implies null 1 − (15/16)^8 ≈ 40.3%, not 6.25%). The fix is text-local: register a binary statistic with its matching null (or a sequence-clustered test with its null calibration), the integer cutoff, and the family rule.

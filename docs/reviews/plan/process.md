30. **Low — Rule 3's freeze trigger is undefined for test-gated phases.** Operating rule 3 freezes thresholds when “the affected phase's first run has been launched” and speaks specifically of “Thresholds in Appendix C” (`PLAN.md:79`). Phases 0-2 are governed primarily by test tolerances and fixtures in phase prose, and Phase 1 has no training run. The conservative trigger could be the first pytest or first `make gate-N`, but neither is registered; a restarted agent cannot tell whether those prose bars are frozen.

31. **Medium — Retrospectives may weaken reviewer/coder instructions without independent review.** “Phase retrospectives and agent evals” requires every optimization to land as “an AGENTS.md entry” or “a tooling or prompt fix under tools/” (`PLAN.md:113`), while the Autonomy policy review-gates only changes to the checker, tracker, and wrappers (`PLAN.md:115`). The kimi retro rubric checks whether the optimization landed and whether blame matches evidence; it does not validate that prompt or AGENTS changes preserve the review/coder contract (`tools/codex-prompts/review-retro.md:5-11`). A retro can therefore weaken `review-phase.md` or instructions automatically loaded by coders, and the change governs the next phase before any sol process review.

32. **Medium — The kimi wrapper does not implement the binding anti-churn rule.** Review-session continuity says kimi receives prior rounds “plus the same anti-churn rule,” under which new findings are limited to regressions or clear original-scope misses (`PLAN.md:111`). The actual kimi preamble preserves prior findings but never states anti-churn and instead says its value is “finding what [sol] missed” every round (`tools/run_kimi_review.py:143-163`). Because confirmed kimi High/Critical claims create mandatory sol adjudication work (`PLAN.md:109`), a stateless reviewer can expand scope indefinitely despite the governing promise.

33. **Low — Phase 5's pilot is underspecified for a matrix whose sequence lengths vary sixteen-fold.** “Budget discipline” requires a pilot-derived total projection (`PLAN.md:107`), while Phase 5 says only “one pilot cell first” for 27 runs spanning `R in {2, 8, 32}` under a 24 GPU-hour budget (`PLAN.md:431`). Task B contains R full segments, each with a delay drawn from 32-256 tokens (`PLAN.md:308-313`), so the R=32 cell is about sixteen times the tokens of R=2 at the same steps and batch. On a single Spark, a conveniently short pilot is not a defensible estimator for the long cells; the 2x human-pause rule may catch the underestimate, but no registered pilot cell or per-R scaling rule makes the 24-hour plan realistic ex ante.

34. **Low — Operating rule 9 still contradicts the mandatory second-reviewer role.** Rule 9 says “all reviews are sol adversarial reviews at xhigh effort” (`PLAN.md:85`), while Section 2b names kimi as the “second, independent reviewer” and requires its run before a gate commit (`PLAN.md:105`, `PLAN.md:109`). The specific checklist prevents a practical skip under the conservative-reading rule, but the global operating rule should say “reviews of record” rather than deny the required cross-review category.

35. **Medium — The G3 sole-authority fix leaves materially contradictory subordinate text in the governing document.** The new block clearly says it “supersedes every earlier phrasing” (`PLAN.md:405`), which resolves Finding 16's bypass. Nevertheless, operating rule 5 still says “Gate states are green, green-with-M1b-primary ... and red” before listing broader qualified states (`PLAN.md:81`); Appendix C still defines G3.4 as “B0-full minus M1” instead of the primary variant (`PLAN.md:500`); Appendix D still says “stop at the first match,” invokes rule 4's three-attempt procedure for G3, and permits a wide model that “does not retroactively pass the 64-pair spec” to continue after amendment (`PLAN.md:509`, `PLAN.md:517-519`). An agent has an explicit precedence answer today, but duplicated dead rules invite incorrect implementation, future edits to the wrong block, and cold-start confusion. The subordinate text should be rewritten as diagnostics only, not left contradictory under a supersession disclaimer.

## Findings

1. **Critical (resolved 2026-08-22: verified column balance and cell-specific nulls) — Task A's cue-blind ceiling was invalid.** Section 6 now says each operand column has distinct outputs for `k <= 16` and two occurrences of every answer for `k = 32`, then correctly registers `1/k` and `1/16` nulls (`PLAN.md:275-276`). Appendix C now uses 14.5% for `k=8` and 8.25% for `k=32` (`PLAN.md:451`). Given the uniform-cue construction invoked by the tests and Phase 4 (`PLAN.md:327`, `PLAN.md:378`), the arithmetic is correct. The separate train/eval rule-seed contradiction is finding 12.

2. **Critical (resolved 2026-08-22: explicit next-token indexing prevents answer leakage) — Answer-token alignment was unspecified.** The new contract states that `logits[p]` predicts `tokens[p+1]`, `loss_mask[p]` selects a next-token answer, and cue distances terminate at decision position `p`; its Task A miniature is internally correct (`PLAN.md:265-278`). A compliant causal model cannot read the answer embedding when producing its own logit.

3. **High — The amended numerical suite still contains an unregistered or impossible damped-energy fixture.** Section 5.2 registers M1b at `g_raw=-9`, hence `G=softplus(-9)≈1.23e-4` (`PLAN.md:226-231`), while Phase 2 requires, merely “with `G > 0`,” that continuous energy at step 10,000 be below `1e-2` of its initial value “at the registered init scale” (`PLAN.md:341`). The damped one-step map has determinant `1/(1+G)`; at the registered `G`, an underdamped modal energy envelope is approximately `(1+G)^-10000≈0.29`, not below 0.01. If another `G` is intended, it, `A`, and the initial state are missing. The same test's `H < 2 H_0` bound is not universal either: at period 8, legal phases reach about `2.293 H_0` under the registered symplectic-Euler map. The corrected discrete invariant and discrete closed form are valid (`PLAN.md:213`, `PLAN.md:340`), but `test_damped_energy_decays` is not an executable oracle as written.

4. **High (resolved 2026-08-22: the complete controller shape/dataflow is now specified) — Controller dimensions and stacked-cell plumbing were undefined.** Section 5.2 now fixes `B_1:64x256`, zero `y_1,z_1`, a `64x64` GLU, `B_2:64x64`, zero `y_2,z_2`, and `c_t=[y_2;z_2] in R^128`, with no extra readout (`PLAN.md:217`). The remaining contradictory shorthand in Sections 5.2-5.3 is isolated as finding 23.

5. **High (resolved 2026-08-22: only M1/M1b are claimed as a controlled dissipation comparison) — H2 falsely treated B2 as differing only in energy handling.** H2 now explicitly calls B2 “a separate architectural baseline” and says it is never a third controlled point, while M1 and M1b share the same cell class and differ in `G` (`PLAN.md:49`, `PLAN.md:255`). This removes the earlier causal overclaim.

Worse, the variant table says B0 has no pathway (`PLAN.md:248-249`) while the prose says both B0 variants “must literally be M1 with the gate module set to `None`” (`PLAN.md:255`), which can mean retaining an unused ~29k oscillator.

Against the registered 6.25% null and 10,000 fresh sequences with eight answers each ([PLAN.md:295](/home/bmarti44/stencil-llm/PLAN.md:295), [PLAN.md:302](/home/bmarti44/stencil-llm/PLAN.md:302)), an 11% result is overwhelming evidence of routing, even if judged too small to be practically important. That permits the headline “strict control/content separation” contribution ([PLAN.md:44](/home/bmarti44/stencil-llm/PLAN.md:44)) to remain formally unqualified after decisive contrary evidence.

16. **High — An unstable trained M1 can pass every gate and masquerade as a conservative oscillator.** Section 5.2 correctly states that boundedness requires `dt * sqrt(A) < 2`, but only says “A is re-checked against the bound after training” ([PLAN.md:213](/home/bmarti44/stencil-llm/PLAN.md:213)). The parameterization enforces only `A >= 0` ([PLAN.md:225](/home/bmarti44/stencil-llm/PLAN.md:225)); no test, threshold, gate consequence, or projection prevents learned `A` from crossing the stability boundary. Appendix C and the G3 exit rule contain no trained-spectrum stability condition ([PLAN.md:449](/home/bmarti44/stencil-llm/PLAN.md:449), [PLAN.md:372](/home/bmarti44/stencil-llm/PLAN.md:372)). M1 could therefore exploit exponential amplification to clear necessity and mechanism bars while invalidating the “exact conservation pole” interpretation ([PLAN.md:252](/home/bmarti44/stencil-llm/PLAN.md:252)) and the claimed bounded, non-forgetting dynamics.

17. **Medium — H2 can be declared supported without task competence or uncertainty separation.** H2 declares support whenever both adjacent mean gaps at `(2048,32)` are at least three points, using only seeds `{0,1,2}` ([PLAN.md:49](/home/bmarti44/stencil-llm/PLAN.md:49)). The cell is record-only and has no minimum accuracy requirement ([PLAN.md:369](/home/bmarti44/stencil-llm/PLAN.md:369)). Results such as 10%, 7%, and 4% would satisfy the registered order even though all three systems are effectively failed around a 6.25% null, and a three-point gap is not compared with between-seed uncertainty. The ordering is falsifiable now, but “supported” is not calibrated to establish a meaningful dissipation advantage.

18. **Medium — The plan does not actually require identical transformer trunks for M1 and M1b.** H2 says the variants “provably differ only in dissipation” ([PLAN.md:49](/home/bmarti44/stencil-llm/PLAN.md:49)), but the parameter-matching rule adjusts `d_ff` per variant based on trainable counts ([PLAN.md:259](/home/bmarti44/stencil-llm/PLAN.md:259)); M1 excludes frozen `G` while M1b includes learned `G`. The bitwise test instantiates only “the unified cell” at zero damping ([PLAN.md:342](/home/bmarti44/stencil-llm/PLAN.md:342)), not the full matched models/configs. Unless the plan explicitly forces identical `d_ff`, shared trunk initialization, and identical non-`G` parameter tensors for M1/M1b, the claimed clean treatment contrast is not a proof obligation.

19. **Medium — Task A's exact null relies on cue/operand sampling semantics that are not registered.** The null derivation asserts that the model faces “k equiprobable” answers ([PLAN.md:276](/home/bmarti44/stencil-llm/PLAN.md:276)), but Task A specifies the rule construction and distractor independence only; it never says how cue indices and operands are sampled or that they are mutually independent ([PLAN.md:275](/home/bmarti44/stencil-llm/PLAN.md:275), [PLAN.md:277](/home/bmarti44/stencil-llm/PLAN.md:277)). Task B, by contrast, explicitly fixes uniform cues and independent uniform operands ([PLAN.md:282](/home/bmarti44/stencil-llm/PLAN.md:282)). A marginal cue-frequency test with distractors held fixed does not exclude cue–operand correlation, which would alter the cue-blind Bayes optimum and weaken H1's information-theoretic claim.

20. **Medium — The damped-energy gate is under-specified and may contradict the registered M1b initialization.** Phase 2 requires, “with G > 0,” decreasing windowed energy and `H` below `1e-2` of its initial value after 10,000 steps “at the registered init scale” ([PLAN.md:341](/home/bmarti44/stencil-llm/PLAN.md:341)), but it fixes neither the tested `A`, `G`, nor random initial-state distribution. If `G` means the registered M1b initialization `softplus(-9) ~= 1.2e-4` ([PLAN.md:228](/home/bmarti44/stencil-llm/PLAN.md:228)), the map determinant implies an energy-envelope scale near `(1+G)^-10000 ~= 0.30`, not `0.01`. If a larger convenient `G` is chosen, the test can pass without validating the actual initialized regime. The fixture must be numerically instantiated before it can serve as a scientific gate.

21. **Low — The control-output definition contains a residual shape contradiction.** Section 5.2 fixes `c_t = [y_2 ; z_2]` ([PLAN.md:217](/home/bmarti44/stencil-llm/PLAN.md:217)), but Section 5.3 calls it “dim 128 from final cell's y” ([PLAN.md:235](/home/bmarti44/stencil-llm/PLAN.md:235)). The equations imply `[y;z]`; the prose should not leave an alternate `y`-only readout in the governing specification.

22. **Low — The explanatory framing still states an untested causal story as fact.** README says shared memory competition “is why assistants drift off their instructions” ([README.md:11](/home/bmarti44/stencil-llm/README.md:11)), while PLAN says the same competition is why assistants drift during long jobs ([PLAN.md:22](/home/bmarti44/stencil-llm/PLAN.md:22)). The registered experiments test a synthetic reachability mechanism, not the cause of instruction drift in deployed assistants; this should be framed as motivation or hypothesis, not an established explanation.

2. Constrain `A` by parameterization to a registered margin below `(2/dt)^2`, or make the trained stability check a mandatory per-checkpoint gate whose failure invalidates the conservative-mechanism claim ([PLAN.md:213](/home/bmarti44/stencil-llm/PLAN.md:213), [PLAN.md:225](/home/bmarti44/stencil-llm/PLAN.md:225)).
3. For every Appendix C row, state whether the bar applies to every seed, min seed, mean of per-seed metrics, or a pooled estimator; explicitly cover G3.1, G3.3, G3.4, both G3.6 clauses, H4 banding, and all G4 tests ([PLAN.md:302](/home/bmarti44/stencil-llm/PLAN.md:302), [PLAN.md:449](/home/bmarti44/stencil-llm/PLAN.md:449)).
4. Separate statistical evidence from practical effect in H4. Report confidence/cluster-aware uncertainty, call any reliably above-null result evidence of routing, register a practical-effect band separately, and require separation-claim qualification for every partial- or strong-leakage outcome, not only `>=50` ([PLAN.md:44](/home/bmarti44/stencil-llm/PLAN.md:44), [PLAN.md:458](/home/bmarti44/stencil-llm/PLAN.md:458)).

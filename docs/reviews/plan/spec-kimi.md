1. **Critical — The registered M1b-init damped-energy fixture has the wrong decay exponent and cannot pass a correct implementation.** Phase 2 `test_damped_energy_decays` regime (b) requires "the `H_10000 / H_0` ratio within [0.8, 1.2] x `(1+G)^(-20000)` (~0.30) — the modal envelope the map's determinant implies" (PLAN.md:359). The formula, the parenthetical value, and the determinant justification are mutually inconsistent. The homogeneous one-step map of the registered update (Section 5.2) is, per mode, M = [[−A/(1+G), 1/(1+G)], [1 − A/(1+G), 1/(1+G)]] with det(M) = −A/(1+G)² − (1/(1+G))(1 − A/(1+G)) + ... = exactly `(1+G)^(-1)` per step (verified symbolically). Underdamped eigenvalue magnitudes are `det^(1/2)`, so any quadratic energy decays as `det^k = (1+G)^(-k)` over k steps. With `G = softplus(-9) = 1.23402e-4` and k = 10,000: correct envelope `(1+G)^(-10000) = e^{-1.2340} ≈ 0.2912` (matching the "(~0.30)" note); the written `(1+G)^(-20000) ≈ 0.0848` yields the acceptance interval [0.0678, 0.1017], which excludes the true dynamics. An implementer following the formula fails G2 on a faithful cell; one following "~0.30" silently disobeys the written threshold — precisely the invention rule 7 forbids. (Independent re-derivation concurring with sol spec#3 and science#20; sol's algebra verified correct.)

2. **HIGH — Unicode separators make AST splicing retain old function code.** `splice_function` indexes `module_text.splitlines(keepends=True)` with Python AST line numbers. `splitlines` also splits actual U+2028/U+2029 and other separators that Python does not treat as source newlines. The actual isolated consumer returns 99 for input 0, although the submitted replacement should return None. This is silent semantic alteration of a valid submitted patch. Split physical source lines consistently with Python while preserving bytes; add exact-splice and executable tests covering U+2028/U+2029 and other splitlines-only separators. 4. **MEDIUM — Functional-mutant discriminators are limited to newly added checks.** Validation supplies `_validate_control` only the current round's functional-check IDs. Validate named functional discriminators against the active stable set, while still rejecting future, inactive-obligation or unrelated IDs. Obligation-mutant names must remain current-obligation checks.

5. **MEDIUM — Permission-tagged checks incorrectly require two distinct expected results.** Validation rejects a permitted/optional rule tag unless `expected_values` has at least two elements. A permission can yield the same observable result for multiple lawful choices, or its optional branch need not fire on this particular input. The contract requires accepting every permitted alternative; it does not guarantee two distinct values for every case. The parent reported this mismatch; inspection confirms it. Preserve type-sensitive alternative matching and independent semantic review, but remove the unjustified cardinality rule.

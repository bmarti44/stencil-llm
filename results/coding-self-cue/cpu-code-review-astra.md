The protocol requires syntax failures to leave state unchanged. This defect can retain an invalid function and poison subsequent integration checks. 2. **HIGH — Unicode separators make AST splicing retain old function code.** `splice_function` indexes `module_text.splitlines(keepends=True)` with Python AST line numbers. `splitlines` also splits actual U+2028/U+2029 and other separators that Python does not treat as source newlines. Replacing alpha through `consume_patch` with `def alpha(x):\n    if x:\n        return x\n` returns a syntactically valid module that still contains the old `return 99` at the end of alpha. The actual isolated consumer returns 99 for input 0, although the submitted replacement should return None. This is silent semantic alteration of a valid submitted patch. Split physical source lines consistently with Python while preserving bytes; add exact-splice and executable tests covering U+2028/U+2029 and other splitlines-only separators. Finding sent promptly to the parent.

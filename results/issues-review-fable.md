### Assessment — grade HIGH (strategic)
The standing goal says "starting with ifeval". The evidence now says the single-turn arena is
closed by the program's own stop-loss, and every single-turn mechanism tried (static x0.25,
deficit-wave, timing gates E0/E2) has either failed its gate or been shown net-harmful on aged
constraints. The only creditable positives are (i) the sealed +18.5 "out-of-reach" win and
(ii) KV pinning recovering 0.615 of the eviction gap (+0.196 over an approximate control).
Both are multi-turn/eviction phenomena. Continuing to frame the program around IFEval
single-turn would be dishonest to the data.

### Defensible next strategy (BRIAN decision; ORCH drafts the registration)
1. Re-state the claim to what the mechanism is designed for: "under context eviction /
   compaction, a pinned-KV ledger restores late-turn adherence to aged instructions at zero
   added context tokens, non-inferior to text re-append." That is a generalization claim over
   BENCHMARKS x AGING, not over single-turn prompts.
2. Benchmarks with aged constraints, in this order (each gated, each preregistered):
   - Multi-IF (en, 909) — already recorded; the ledger runner exists. Fix F1 first.
   - Multi-IF with FORCED EVICTION of turn-1/turn-2 user text (the KV-probe design applied
     to a real benchmark): arms full / evicted / evicted+text-reappend / evicted+pinned /
     evicted+pinned_control. This is the experiment that turns the synthetic KV result into a
     benchmark result and is where the mechanism has headroom (eviction gap 0.464 synthetic).
   - IFBench (300 prompts, unseen taxonomy) in the same multi-turn/eviction harness for the
     transfer axis; SysBench or MT-Bench-style system-prompt persistence for a second
     "aged instruction" family if the first two pass.
   - Sealed IFEval single-turn: only as a FINAL non-regression check (bitwise-OFF == base when
     the ledger is empty is already the deploy invariant), never as the headline.
3. Preregistered gates (reuse the machinery already verified by sol rounds 1-6):
   - Primary: conversation-clustered NI of neural/pinned vs text re-append, margin 2.0,
     continuity-corrected t (stats.py:255), with the F1-amended truncation gate.
   - Non-vacuity: text-beats-base clustered lower bound > 0 on all eligible AND selected
     cells (already registered). Neural-beats-base clustered lower bound > 0 (registered).
   - Generalization gate: the primary must hold on >= 2 benchmarks with different constraint
     taxonomies (Multi-IF, IFBench) — pre-declare that one pass + one fail = "does not
     generalize", no rescue.
   - Cost gate: neural context tokens added == 0 measured per turn (registered).
4. Headroom reality check before spending GPU: on the 909, base passes 491/671 = 73.2% of
   eligible (aged AND insertable) cells, so the addressable headroom is 180 cells (26.8%);

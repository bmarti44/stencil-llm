# Fresh automatic-focus reasoning pilot — prospective draft

2026-09-08. Fit-on: none. Development-on: two wholly new Kimi K3 projects,
authored through Ollama without earlier examples or responses. Evaluated-on:
none. All earlier cases remain spent DEV, excluded from this bank and fitting.
No larger-test files are reopened. This draft is not launch authorization.

The completed native reasoning/tool smoke is independently audited PASS.
Astra's subsequent assessment says another manual-only qualification is optional
and could become a detour. Test an automatic path now, without claiming that a
small pilot proves parity with useful manual reminders. Superiority over manual
prose is not required. A trained interpreter remains a later candidate; no
training is performed or inferred here.

Hypothesis: the existing checkpoint's native reasoning mode and separate typed,
source-grounded selection can produce usable current reminders while its code
worker uses actual edit/test feedback. This is a new operating point after the
nonthinking disposable reader and same-response self-cue failures, not a rerun
or revised verdict on either. There is one prospective attempt on fresh data.
Failure parks this fixed automatic reasoning recipe; no cosmetic prompt rescue.

Each of two independent projects contains three connected requests. For each
request, make one cold selector call using only the authentic conversation
prefix, its source IDs, and the current request/task handle. No reference code,
manual recap, oracle rules, checks or generated worker reasoning enter selection.
The selector returns one named `record_focus` tool action with exactly
`obligations`: a list of objects each containing `text` (nonempty prose) and
`source_ids` (nonempty list of visible message IDs). The tool schema restricts
source IDs to the actual visible prefix; structural checks cannot establish
semantic completeness, authority, correct scope or entailment.

Selection is disposable: retain all original source events, not an authoritative
mutable summary. No source is deleted. Render every returned obligation verbatim
in a current-request block supplied to both allowed coding attempts. Keep that
block out of persistent worker history, and never replace a missing or incorrect
reminder with manual/oracle content. Select again from the fresh authentic prefix
on the next request. Inspect selector completeness and authority independently
against the source after the run, including retired and quoted instructions.

The worker sees authentic conversation, its actual current module, actual prior
tool calls/results, and this automatic reminder. It gets at most two candidate
edits per request, stopping only after applied code passes fixed public checks
or both attempts are spent. It never sees private expected outputs or scores.
Compile and function-subset errors can consume the remaining attempt; transport,
token/schema/context/cap errors terminate the whole batch as INCOMPLETE. Private
endpoint checks run once after the public-only stopping decision. Earlier failed
endpoints remain failed. No reference reset or human correction is permitted.

Maximum: 6 selector calls + 12 worker calls = 18 generations, each with an exact
same-byte native render first. Use the already tested original checkpoint/image,
native qwen3 reasoning/Hermes tools, temperature .6, top_p .95, top_k 20, min_p 0,
seed 20260908, context 32768, output cap 2048, thinking allowance 1024. This larger
thinking allowance and selector tool are not yet runtime-qualified. Validate
native actual fields, boundaries, exact arguments, prompt/output IDs and usage.
Final-only tool history; no reasoning replay or causal-forcing claim.

The remaining final-output allowance at the full thinking boundary is 1021
tokens after reasoning delimiters/EOS. Before inference, independently reviewed
reference edits and complete reference focus objects must fit with at least 128
tokens spare. Do not simplify semantic tasks to achieve capacity eligibility.
Reference focus serialization is an offline capacity check only, never a runtime
fallback. Actual native renders must fit on every call with full output reserve.

Prospective narrow continuation rule: at least one of two complete projects
passes all three actual endpoint check sets, has no material implementation or
dependency defect under independent source review, and has complete, source-
supported current focus at all three requests under independent semantic review.
Report all six endpoints, all selector defects, attempts, tokens, timings and
human interventions (expected zero), regardless of the decision. Source review
cannot discard a failed project or erase a failed endpoint. A pass demonstrates
one usable automatic workflow only, not reliability, causation, equivalence,
noninferiority or adequate larger proof. A later adequately sized fresh paired
comparison remains necessary before the full goal can be called achieved.

The isolated `uv run --with jax==0.4.35` environment would not even have the upstream packages importable. Consequences: (a) the fixture can never detect the very divergence it exists to detect — PLAN §5.2 mandates verifying the undamped and damped forms against the actual LinOSS/D-LinOSS equations and recording any material discrepancy as an amendment; this fixture is blind to it; (b) the acceptance-chain record is false — the LEDGER's topmost STATE entry claims "fourth independent implementation agreement: orchestrator hand-exec, sol reconstruction, production code, upstream JAX", but no upstream JAX code ever ran; the true chain is hand-executed references agreeing with production code, which is strong but categorically weaker; (c) `test_cell_matches_jax_fixtures` passes (gate-2 green) while its registered subject is absent — the test honestly compares against the npz, but the npz's provenance is not what the PLAN registers.
